# ERP 底座实施计划

> 使用 superpowers:executing-plans 执行，逐项记录验证结果。

**目标**：从轻量权限后台建立可独立部署的 ERP 底座。

**设计**：[首版底座](../specs/2026-11-17-erp-foundation-design.md)

- [ ] 在临时目录检出 SenQi-666/fastapi-vue-admin，记录提交、许可证、Python 和 Node 版本、数据库及 Redis 依赖。检查登录、账号停用及后端权限入口。
- [ ] 使用独立测试数据库初始化候选项目，启动前后端。用管理员创建员工并分配受限角色，检查可访问的功能正常，直接调用受限管理接口返回拒绝，停用后旧会话无法访问受保护接口。记录差距和改造成本。
- [ ] 候选适用时按已核验的提交导入，保留许可证和来源说明。沿用现有模块边界，补齐验证发现的权限缺口。为角色撤销后旧会话和账号停用增加回归验证。
- [ ] 新增公司基本信息和关键管理操作日志。验证普通员工无法修改公司资料或读取管理日志，管理员可看到账号启停及角色分配的操作人、时间、对象、动作。验证无效更新不会产生成功日志。
- [ ] 准备独立部署配置和初始化说明。用空数据库走一遍初始化、首次登录及角色分配，再用另一套独立配置验证数据互不相通。记录运行依赖和客户专属模块的配置方式。
